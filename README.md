# மஞ்சள் அழைப்பு

Create a beautiful, elegant, traditional Tamil invitation website for a மஞ்சள் நீராட்டு விழா.

IMPORTANT:

The entire visible website must be in Tamil only.

Do NOT use English words for headings, buttons, navigation, event information, or descriptions.

Use elegant Tamil typography throughout the website.

The website should feel like a premium traditional Tamil family function invitation, not like a generic modern event website.

The design must be mobile-first and look excellent on Android phones.

Use smooth, subtle animations. Do not make it flashy or over-animated.

The overall visual style should be inspired by the FIRST REFERENCE IMAGE provided by the user.

1. MAIN VISUAL THEME

Use the first reference image as the primary visual inspiration.

The website should have:

Warm ivory / cream background

Traditional gold borders

Soft maroon / rose-gold typography

Dark green accents

Traditional Indian floral decorations

Jasmine and pink flowers

Mango leaves / thoranam elements

Traditional brass kuthuvilakku

Small hanging bells

Elegant ornamental separators

Soft golden glow

Subtle temple/family-function atmosphere

The design should look luxurious but traditional.

DO NOT make it look like:

a corporate website

a wedding website

a generic birthday website

a modern SaaS landing page

It must clearly feel like a Tamil குடும்ப விழா / மஞ்சள் நீராட்டு விழா அழைப்பிதழ்.

2. GIRL / DOLL CHARACTER

The most important visual element from the first reference image is the traditional Indian girl/doll character.

Create or use a beautiful illustrated traditional Tamil/Indian young girl character standing gracefully, wearing a traditional half-saree / பாவாடை தாவணி style outfit.

Visual characteristics:

Long dark flowing hair

Traditional jewellery

Small forehead ornament

Earrings

Necklace

Bangles

Traditional waist belt

Elegant half-saree

Green and pink/maroon colour combination

Gold embroidery

Graceful standing pose

Soft illustrated / premium digital-art appearance

Cute but elegant

Family-function appropriate

The character should visually resemble the girl/doll composition in the FIRST REFERENCE IMAGE.

IMPORTANT:
The character should NOT be a real person's photo.
It should be an elegant illustrated invitation character.

Place this character prominently in the hero section, preferably on the left side on desktop and centered on mobile.

The same character can appear again in smaller decorative positions in other sections. Reusing the character is acceptable and encouraged to maintain visual consistency.

3. TOP OF THE WEBSITE

At the very top, display this exactly:

ஶ்ரீ சோனையன் துணை

Use an elegant traditional Tamil font.

Below it, add a small ornamental gold divider.

4. HERO SECTION

Create a visually rich hero section inspired by the first invitation image.

Main heading:

மஞ்சள் நீராட்டு விழா

Below it:

அன்புடன் அழைக்கிறோம்

Then introduce the girl:

செல்வி. S. அம்ரிதா

Below her name:

P. சங்கர் – தமிழ்செல்வி அவர்களின் மகள்

Also mention the location context:

தஞ்சை மாவட்டம், பந்தநல்லூர்

The girl/doll illustration should occupy a major visual portion of this section.

Use subtle floating flower-petal animation and a very soft golden glow.

Do NOT overcrowd the hero section.

5. INVITATION MESSAGE

Create a traditional Tamil invitation section.

Use elegant Tamil wording similar in feeling to a traditional family invitation card.

Suggested content:

எங்கள் இல்லத்தில் நடைபெறும் இனிய மஞ்சள் நீராட்டு விழாவிற்கு தங்களையும் தங்கள் குடும்பத்தினரையும் அன்புடன் அழைக்கிறோம்.

Then:

தங்களின் அன்பான வருகையும் வாழ்த்துகளும் எங்கள் விழாவை மேலும் சிறப்பிக்கும்.

Keep the wording warm, respectful and traditional.

6. EVENT DETAILS

Create a beautiful traditional event-details card.

Heading:

விழா நாள் மற்றும் நேரம்

Display:

ஆவணி மாதம் 27 ஆம் தேதி
13-09-2026, ஞாயிற்றுக்கிழமை

Time:

காலை 10:30 மணி முதல் 11:30 மணி வரை

The date and time must be visually prominent.

Use traditional gold ornamental borders around this section.

7. CEREMONY INFORMATION

Add a separate section:

மஞ்சள் நீராட்டு விழா

Explain that the ceremony is taking place at the family's home in Pandanallur.

Use:

இடம்: தஞ்சை மாவட்டம், பந்தநல்லூர்

Do not invent a house name, street name, or exact address if it has not been provided.

8. LOCATION BUTTON

Create a prominent traditional button:

வழியைக் காண

When clicked, open this exact Google Maps location:

https://maps.app.goo.gl/4fYjH67bdgZS3cVd9

The button should have a small location-pin icon.

Optionally display a small embedded map preview if technically possible.

The visible text must remain Tamil.

9. FAMILY INVITATION STYLE

The SECOND REFERENCE IMAGE is a traditional Tamil invitation card.

Use it only as a design/content-style reference.

Do NOT copy its family names, date, event details, or unrelated information.

Extract the visual structure from it:

Traditional Tamil invitation hierarchy

Large red/maroon Tamil heading

Green supporting text

Decorative border

Formal family invitation wording

Traditional spacing

Respectful tone

But replace all those details with the actual information provided in this prompt.

11. DECORATIVE ELEMENTS

Throughout the website use tasteful traditional decorations:

Gold ornamental corners

Mango leaf thoranam

Jasmine flowers

Pink flowers

Small hanging bells

Brass kuthuvilakku

Traditional floral borders

Gold ornamental lines

Soft flower petals

Subtle traditional patterns

Keep the decorations elegant.

Do not make the page visually noisy.

12. WEBSITE SECTIONS

Build the website as a single elegant scrolling invitation.

Sections:

முகப்பு

அழைப்பு

விழா விவரங்கள்

மஞ்சள் நீராட்டு விழா

இடம்

வாழ்த்து / நிறைவு அழைப்பு

Navigation, if used, must also be completely Tamil.

For example:

முகப்பு | விழா | விவரங்கள் | இடம்

13. FINAL SECTION

At the bottom create an elegant closing invitation.

Display:

தங்களின் அன்பான வருகையும் வாழ்த்துகளும்
இந்த இனிய நாளை மேலும் சிறப்பிக்கும்.

Then:

அன்புடன் அழைக்கும்

P. சங்கர் – தமிழ்செல்வி

Below this, use a small floral/gold ornament.

14. DESIGN DETAILS

Use:

Responsive design

Mobile-first layout

Elegant Tamil fonts

Large readable Tamil text

Smooth scrolling

Subtle fade-in animations

Soft flower-petal effects

Gentle parallax effect for decorative elements

Premium spacing

Rounded cards only where appropriate

Traditional gold borders

Cream/ivory base background

Avoid:

Excessive gradients

Neon colours

Dark modern UI

Excessive animations

Large buttons everywhere

Generic stock wedding templates

English text

Placeholder text

Fake information

15. MOBILE EXPERIENCE

The website will primarily be viewed on mobile phones.

On mobile:

Girl illustration should remain clearly visible.

Text must not become too small.

Event details should be easy to read.

Location button should be large enough to tap.

Decorative elements must not cover the text.

The invitation should feel like a digital Tamil invitation card.

16. OVERALL RESULT

The final website should feel like:

ஒரு அழகான, பாரம்பரியமான, உயர்தர தமிழ் மஞ்சள் நீராட்டு விழா அழைப்பிதழ் — இணையதள வடிவில்.

The SECOND REFERENCE IMAGE controls the traditional Tamil invitation-card feeling and information hierarchy.

The actual event details provided in this prompt MUST override any details appearing in the reference images.

Do not copy incorrect names, dates, venues, or other information from the reference images.

The final result must look like a real family-created invitation website rather than an AI-generated generic template.
